# Casos de prueba funcionales — CheckU Web

## HU4. Proyección del código QR

| ID | Caso de prueba | Resultado esperado |
|---|---|---|
| WEB-HU4-01 | Acceder a la pantalla de sesión QR | Se muestra la interfaz correspondiente a la sesión |
| WEB-HU4-02 | Visualizar el código QR de una sesión activa | El código QR se muestra correctamente |
| WEB-HU4-03 | Consultar una sesión cerrada | No se permite proyectar un QR como si la sesión siguiera activa |
| WEB-HU4-04 | Actualizar la vista de una sesión | La información de la sesión se mantiene coherente con su estado |
| WEB-HU4-05 | Comprobar la visualización desde una ventana de navegador | La interfaz se adapta al espacio disponible sin ocultar el QR |

## Registro de ejecución

Los casos quedan pendientes de ejecución en la aplicación. Se documentarán los resultados reales después de realizar las pruebas.
